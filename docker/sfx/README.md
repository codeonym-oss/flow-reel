# Flow Reel UI sounds

Creator: DAEDAL. Licence: CC0-1.0 (see LICENSE.txt). Official source: https://daedal.art/resources/ui-sounds/ . Downloaded 2026-11-11 from the official GitHub release URL in manifest.json. The source ZIP and original licence are retained in GH-8’s planning audition folder, outside the runtime package.

The first Kenney palette was functional, but listening feedback described it as too quiet and generic. This revision uses related DAEDAL clicks, paired movement sounds and softer tonal tails. Selected files are derived 48 kHz stereo 24-bit WAVs. manifest.json records original filenames/source hashes, every FFmpeg filter and shipped-file hashes. Source originals remain in the archived ZIP. No runtime generation, downloads or additional libraries.

Runtime decoding uses normalized mono channel averaging (no stereo downmix boost), near-silence trimming (absolute amplitude <= 0.0001) and 1 ms attack / 3 ms tail fades. Calibrate click/action RMS to active narration RMS minus 12 dB, typing minus 18 dB. The narration reference is RMS across 100 ms windows above -50 dBFS; without narration use -20 dBFS. Attenuate the combined SFX bus only if its sample peak exceeds -18 dBFS. Duck another 6 dB over narration intervals, with a 30 ms lead-in and 250 ms recovery. Truncated tails get a 3 ms fade. SFX-only demos retain these fixed quiet levels; final voiced mixes retain the inherited loudness/true-peak checks. These are starting levels after user feedback, not an instantaneous speech/SFX ratio guarantee. Final sound selection still requires playback approval.
