# 001: Demos serve anyone who needs to see a feature

**Date:** 2026-11-02 (shaping, Q1; agreed: "yes, anyone intressted reviewers clients etc ....")

**Question:** who needs these demos: PR reviewers, product/client audiences, or both?

**Decision:** **anyone: reviewers, clients, users.** One pipeline serves them all; honest PR evidence and polished
client demos differ only in later output presets, not in separate tools.

- **Why:** the same recording answers "does it work?" for a reviewer and "what does it do?" for a client.
- **Not chosen:** reviewers only, or clients only — either would split the tool later.
