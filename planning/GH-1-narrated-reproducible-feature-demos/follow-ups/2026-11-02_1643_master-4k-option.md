# Offer a 4K master on machines that can encode it in real time

GH-2 decision 005 set the master to 1440p because 4K x264 can't keep up on a 4-core CPU while Chromium renders
(0.63× real time). A `--master 4k` option, and later a GPU encoder (VAAPI, NVENC) choosing 4K by default when present,
would give sharp 2× zooms (GH-7) where the hardware allows. The runner's real-time check (master no more than 3 %
shorter than wall-clock) already guards a machine that can't keep up. Best picked up with or after GH-7.
