## Implementation contracts

- Context helper: `sfx(name): void`, with exported `SfxName` union of the eight agreed names. Validate at runtime and fail clearly on unknown names even when rendering is muted. Record `{t, type: "sfx", name}` at the current clock time, with no sleep, playback, network request or browser action.
- Event compatibility: introduce event-log version 2 for new recordings, while the updated validator accepts version 1 logs with their existing event types and version 2 with the added `sfx` event. Keep transcript schema version 1 unchanged. Document that old tools rejecting v2 must be upgraded; do not mislabel new event types as the old v1 contract. Extend types/fixtures without gratuitous rewrites. Marker shift and hold remapping apply exactly once to cues, like other events.
- Filter audio-only events out before camera lookahead. A cue inserted between a move and click must not change any camera, pointer or ripple sample. Cues never extend zoom deadlines.
- Automatic click placement uses exact delivery event time rounded to a 48 kHz sample; first ripple frame may be up to one frame later. Suppress an automatic click sound if an explicit cue is within an inclusive ±150 ms on the final delivery clock. Preserve logged clicks/ripples. Explicit cues remain intentional and are not silently deduplicated.
- Typing uses Unicode code-point iteration consistent with the installed Playwright implementation, with a tap at `event.t + index * charDelayMs` (verify the installed delay placement before coding; if Playwright delays the first key, align this formula to that observed contract). No taps for empty text. Do not split surrogate pairs; follow actual character dispatch for whitespace and combining marks. Existing event pacing is approximate intent, not per-keystroke measured capture. Use a stable 0/1/2 cycle across the sorted recording; no random choice and no wrapper/pacing rewrite.
- Retain event order for equal timestamps; never mutate caller events. Ignore non-audio move/scroll events; drop sounds starting outside delivery and trim tails to the exact delivery sample count. Zero-delay text and simultaneous cues must remain finite and bounded by a deterministic SFX-bus peak reduction.
- Pack only the chosen click + three typing + eight cue assets, source licences and a small provenance manifest under `docker/sfx/` (already covered by npm's `docker` allowlist). Resolve assets relative to the installed package with `import.meta.url`, never cwd or planning. Add a late `COPY docker/sfx` to the image, avoiding TTS cache invalidation. Use existing FFmpeg/Node; no new runtime dependency or download.
- Preserve `.flow-reel/<name>/voice.wav` as normalized voice only. Assemble disposable `sfx.wav` and `mix.wav` under that demo's work folder; no transcript SFX metadata or extra public output format is needed. Remove stale generated SFX/mix intermediates when disabled or no effects exist.
- `record(script, {sfx?: boolean})`, host `launch` and pure `buildRunArgs` forward a boolean defaulting true. Accept `--no-sfx` before or after the script; reject unknown flags, extra positionals and duplicate flags with usage exit 2. Keep `compare` arguments unchanged. Disabling SFX still records/validates explicit cues and preserves visuals, voice, captions and timing.

4. **Assemble SFX and mix under narration.** Decode each selected asset once to 48 kHz PCM using FFmpeg, then place/accumulate with deterministic arithmetic into a fixed-length stereo buffer. Avoid one subprocess/input/filter per character, giant command lines, or quadratic whole-history expressions. Keep normalization of original voice unchanged. Calibrate per-asset gain against a documented active-speech RMS reference, aiming clicks/action cues 18 dB below the reference before ducking, typing 24 dB below. Define the reference as the RMS over 100 ms voice windows above -50 dBFS; use a fixed -20 dBFS RMS reference for no-voice demos. Define asset RMS over its trimmed active support. Cap the whole assembled SFX bus at -24 dBFS sample peak by attenuation only, so overlaps cannot accumulate into startling output. These are starting calibration values subject to measured preview evidence, not a guarantee of an instantaneous dB ratio during every quiet phoneme.

   Use known narration clip intervals for deterministic ducking: ramp SFX gain from 0 to -6 dB during the 30 ms before speech starts (clamped to delivery start), hold through the full clip including internal pauses, and recover over 250 ms after clip end. Overlapping envelopes take the strongest attenuation. Mix SFX with the normalized voice, preserving both durations; produce 48 kHz stereo AAC as today. With voice and actual effects, two-pass normalize the final mix to the inherited target; apply shared gain to both components so their relative balance is preserved, and measure the result. With SFX disabled/absent, use the existing voice-only path exactly. With SFX only, retain fixed quiet gains and peak protection; no -16 LUFS normalization. With neither, retain video-only output. Preserve exact sample count after filters, including dynamic loudnorm resampling; decoded AAC duration stays within one frame. Keep clean master video and source WAVs unchanged.
   → check: decoded synthetic fixtures prove individual onsets, three typing variants, exact duck ramps/overlap recovery, SFX gain and peak caps, preservation of late narration/tails/holds, source hashes, and voiced final loudness (-16 ±1 LUFS, existing -1.4 dBTP operational tolerance). SFX-only peaks remain quiet and source gains do not depend on silence length. Two identical renders yield identical decoded PCM in the same image. ## Tests and risks

- **Schema/API compatibility:** v2 event logs are an explicit new contract; transcript stays v1, new readers accept old logs, and no-event/legacy scripts remain valid. Test actual runtime loading as well as types.
- **Visual regression from cue adjacency:** filter audio-only events before camera planning; compare sampled plans and decoded representative frames. Do not reset approved 650/2000/800 ms zoom timing.
- **Masking and normalization:** fixed gain calibration plus ducking is testable but not a substitute for listening. Check dense overlaps and short transients; final normalization must not reverse speech/SFX hierarchy or amplify SFX-only clips.
- **Timing limitations:** type logs describe intent with fixed per-character delay, not observed browser key timestamps. Verify the installed Playwright iteration/delay contract and document limits. No unplanned recorder/action-log rewrite.
- **End trimming:** effects may truncate by the agreed no-extension rule; use a brief fade at a truncated tail to avoid a boundary click. Never truncate speech or change holds to fit an SFX cue.
- **Missing assets:** fail clearly instead of silently substituting sounds; validate assets only when effects are needed, so muted/empty paths remain valid. Package/image smoke tests catch source-tree-only assumptions.
- **Performance:** mix one fixed-length output buffer with decoded asset reuse; no per-character FFmpeg process or input. Exercise long typing and simultaneous events without new configurable infrastructure.
- **Scope:** no new semantic detection, arbitrary asset paths/themes, broad sound library shipping, dependency additions, 4K, recorder bugfixes or CI changes.
