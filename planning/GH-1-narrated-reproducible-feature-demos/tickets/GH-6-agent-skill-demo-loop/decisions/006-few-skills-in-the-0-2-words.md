# 006: A few skills in the 0.2 words, one of them all-in; the depth is in references

**Supersedes 001** in part: its eight-skill split. One `flow-reel` plugin, shared references and small helpers, and
no composing logic in the plugin still stand.

**Date:** 2026-11-15 (re-plan for 0.2, Q1; agreed: "id choose the both worlds of 1 & 3 ; fewer SKILLs can be better
right? instead of confusing agent, human about + 10 skills, just some, and an all-in skill will be best! for the
references, add some for the scenes, direction, etc .. how to built professional views using SFX and Sounds ....")

**Question:** the planned skills are named `*-demo`, and "demo" is a word `CONTEXT.md` says to avoid. Rename all
eight to the 0.2 words, keep the names, or ship fewer skills?

**Decision:** **ship a few skills, named in the 0.2 words.** One all-in skill takes a request from start to finish:
plan, explore the app, write the script, compose, review. The other skills cover only the jobs someone asks for on
their own (the set is decided next). Editorial depth lives in references that the skills load when needed: building
scenes, directing the picture with effects, and designing with sounds, so that a reel looks professional.

- **Why:** a person or an agent choosing among ten skills that overlap gets confused; one entry point that does the
  whole job is easier to find and trigger. References hold the know-how without growing every prompt.
- **Not chosen:** eight renamed skills (too many overlapping triggers); keeping the `*-demo` names (the plugin that
  teaches the language would break it). Descriptions may still say "demo", since that is how people ask.
