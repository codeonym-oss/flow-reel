# 013: A run is autonomous or human in the loop; human in the loop is only in the studio

**Superseded by 014.**

**Date:** 2026-11-25 (stated by the person: "there are two kinds of exec mode, the autonomous mode! and the human in the
loop mode (only via studio) … because in studio we can intercept a ran, pause it")

**Decision:** **there are two execution modes.** An autonomous run needs nobody. A human-in-the-loop run exists only in
the studio, where the person can intercept and pause it.

- **Open:** whether the studio can take over an autonomous run; editing a run, which the person wants possible later
  ("later on, we may even be able to edit it ?").
