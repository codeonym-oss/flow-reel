# 005: Resuming uses what the run started with, whatever changed since

**Date:** 2026-11-25 (grilling, Q5; agreed: "1, what the run started with")

**Question:** the script, its files or the settings changed since a run stopped. What does resume use?

**Decision:** **what the run started with.** When recording ends, the run keeps its own copy of everything the later phases
need: the cue sheet, card pages, images, brand and settings. Resume finishes that reel and says when the script has changed
since the recording.

- **Why:** a run is one fixed version of the project from start to end, and the project can change while a detached run goes
  on.
- **Accepted cost:** the finished reel can be older than the script.
- **Not chosen:** refusing to resume (a one-word fix would throw away a good recording); the old recording with the new
  settings (the reel would match no single version of the project).
- **Open:** when a queued run reads its script and settings: as it is queued, or as its recording starts.
