# Docs, the migration and the three systems

## Problem

The docs describe 0.7, and some of this story's behaviour depends on the operating system.

## Change

- **Docs:** workspaces, scripts, runs, the commands, the reel format without `work/`, CI, troubleshooting, and the
  **migration from 0.7**.
- **The three systems:** the unit tests and the host's commands without Docker run on Linux, macOS and Windows in CI. What
  can't run there is listed for the person's check.
- **Speed and fidelity:** the same scripts composed on 0.7 and here, compared and timed.

## Done when

- A 0.7 project follows the migration page and composes.
- The story's own "done when" holds, each with the test or command that shows it.
- The decisions this story changes are marked superseded.
