03 · Status

What each color means

A run is always in one of these states. Color is never the only sign: each has its own shape and word.

running

Emerald, pulsing. The run is recording, voicing or rendering.

now · 00:14.2

Yellow line. The playhead: where the run or the reel is right now.

needs you

Solid yellow. Something waits for a person: a failed step to look at, a choice to make.

failed

Red, and only here. A step failed; the run stopped.

done

Ink with an emerald dot. The reel is composed.

waiting

Grey ring. Waiting for another run before its heavy work.
